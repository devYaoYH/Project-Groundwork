How to change which model an experiment uses

In an experiment config — replace the inline agents: block with a top-level participants: list. One entry per seat, in order. For games/buyer-seller/experiments/example.yaml:

defaults:
  game_name: buyer_seller
  num_agents: 2
  agents:                      # delete this block…
    - {type: llm, model: gpt-4o-mini}
    - {type: llm, model: gpt-4o-mini}

participants: [ds-flash, ds-flash]   # …and add this at the top level

model: takes a provider's model string, never a pool name. model: ds-flash resolves to no provider and fails at the first call — use participants instead.

To add or re-route an agent — edit experiments/agents.yaml, or copy an entry into agents.local.yaml at the repository root to change how you personally reach a provider. That file is gitignored and shadows the shared defaults by name, so shared configs stay portable.

# agents.local.yaml — same name, your route
agents:
  haiku:
    model: anthropic/claude-haiku-4.5
    api_format: openai
    api_base: https://openrouter.ai/api/v1
    credential: OPENROUTER_API_KEY

Edits are picked up on the next request. The workspace is baked into the image, so run docker compose up --build after editing on the host.
