Algorithm — simulated annealing

▼

The generator uses simulated annealing (SA), a stochastic local-search metaheuristic that approximates a global optimum of a non-convex objective by accepting worsening moves with a temperature-dependent probability — allowing escape from local minima early in the search and converging to a near-optimal solution as the system cools.

Problem formulation

Let P be the set of projects, R the set of resource types, and Z = {p1, p2, unassigned} the set of zones. The solver searches over the joint space:

  • Assignment σ : P → Z, subject to |σ⁻¹(p1)| ≥ 2 and |σ⁻¹(p2)| ≥ 2
  • Reward r(p) ∈ [1, 10] ∩ ℤ for each p ∈ P
  • Resource quantities q(p, ρ) ∈ [1, 6] ∩ ℤ for each p ∈ P, ρ ∈ R(p)

The following are fixed external parameters not modified by the solver: number of resource types |R|, per-unit resource costs c(ρ), cash budget B (identical for both players), and which resource types each project uses.

Objective function

Define the individual maximum reward for player i as:

V_i(σ, q, r, B) = max over feasible run-count vectors n satisfying resource and budget constraints of Σ n(p)·r(p)

The combined score is C = V₁ + V₂. The true collaborative maximum M is the optimal combined reward when both players draw simultaneously from the shared resource pool, including synergy bonuses (a joint integer program solved by bounded enumeration). The M/C ratio = M / C characterises resource interaction across three regimes:

  • M/C = 1 (non-interfering): joint play recovers exactly the sum of individual optima — projects use disjoint resources and no synergies apply. Distributive game; the pie is fixed.
  • M/C ∈ (0,1) (partially interfering): resource contention means joint play recovers less than individual optima summed. Partially competitive.
  • M/C → 0 (destructive): near-total contention; simultaneous play collapses combined reward. Negative-sum.
  • M/C > 1 (superadditive): synergy bonuses make joint purchasing strictly better than solo play — cooperation produces surplus value. True cooperative game in the game-theoretic sense.

Synergy bonuses are project-level conditions of the form: if total units of resource ρ purchased by both players combined ≥ θ, then the triggering player receives an additional +β reward per run of that project. This is evaluated after all purchases are made using only publicly observable information (total resource consumption), preserving project privacy. Formally, the effective reward is:

r̃(p, n_p, u_other) = r(p) + β(p) · 𝟙[n_p·q(p,ρ) + u_other[ρ] ≥ θ(p)]

The solver minimises the composite loss, where τ ∈ [0, ∞) is the user-supplied target M/C ratio (values > 1 target superadditive outcomes):

L = |M/C − τ| · 100 + 300 · 𝟙[τ≤1 ∧ M/C>1] + 0.5 · (|V₁ − V₂| / max(C,1)) · 100 + 1.5 · |C − 40| + 200 · 𝟙[C < 2]

The first term drives M/C toward τ. The second is a hard penalty preventing synergy leakage when targeting τ ≤ 1. The third penalises player asymmetry. The fourth anchors the combined score C near 40 (≈20 per player), reducing variance in reward magnitude across different M/C targets. The fifth guards against degenerate zero-reward solutions.

Search procedure

At each iteration the solver samples a neighbouring state via one of four equiprobable move operators:

  1. Reassign — move one project to the next zone in the cycle p1 → p2 → unassigned → p1, provided the source player zone retains ≥ 2 projects.
  2. Reward perturbation — increment or decrement r(p) by 1 or 2 for a uniformly sampled project p.
  3. Quantity perturbation — increment or decrement q(p, ρ) by 1 for a uniformly sampled (project, resource) pair.
  4. Player swap — exchange the zone assignments of one project from each player, preserving the min-2 constraint.
  5. Synergy perturbation — for a uniformly sampled project: add a synergy condition (random resource, threshold, bonus), remove an existing condition, or perturb threshold θ or bonus β by ±1–2. This allows the solver to discover superadditive configurations when targeting M/C > 1.

A candidate state s′ with loss L(s′) is accepted with probability:

P(accept) = 1 if L(s′) ≤ L(s), else exp(−(L(s′) − L(s)) / T)

Temperature decays geometrically: T_k = T₀ · α^k, with T₀ = 80, T_min = 0.5. The decay rate α is calibrated to span the full iteration budget exactly: α = (T_min / T₀)^(1 / K_max) = (0.5 / 80)^(1/5000) ≈ 0.99895, ensuring T reaches T_min precisely at step K_max = 5,000. Each outer step evaluates 12 candidate neighbours, giving a total evaluation budget of 60,000. The search terminates at whichever comes first: (a) exhaustion of the 5,000-step budget, or (b) early exit when the best loss L falls below 0.5, indicating a near-perfect match to the target M/C with negligible player gap. The best state encountered across all iterations is retained and applied regardless of the final current state.

Theoretical M/C floor

The M/C ratio is bounded below by 0.5 (assuming balanced players). The joint optimum M can always assign all resources to whichever player has the higher individual maximum, guaranteeing M ≥ max(V₁, V₂). Since C = V₁ + V₂ and max(V₁, V₂) ≥ C/2, it follows that M/C ≥ 0.5. Equality holds when V₁ = V₂ and both players compete for exactly the same resources. The target slider is therefore clamped to [0.5, 1.5]: the left endpoint is the tightest achievable interference floor; 1.0 is non-interfering; values above 1.0 require active synergy bonuses.

Complexity note

Evaluating V_i is O(B · |P_i|²) via a bounded two-project loop. Evaluating M requires enumerating run-count combinations up to a per-project cap of 10, giving worst-case O(10^|P|) — kept tractable by the small problem size (≤ 5 assigned projects). The full SA run is O(K · eval) where K = 60,000.
