Building Common Ground

A research platform for studying dynamic grounding in LLM negotiation dyads. Two agents share scarce resources and hold private projects — they must build shared understanding through interaction to coordinate, but talk is cheap and every promise is non-binding. Can they bridge the gap between individual planning with full information and joint coordination through communication under asymmetric information?

Assign Projects
Each agent receives private projects that require specific resources. Projects have different payoffs — agents must decide which to pursue.
Cheap Talk
Agents exchange free-form messages — they can signal, bluff, or coordinate. Talk is non-binding: agents can say anything.
Simultaneous Purchase
Both agents submit resource orders at the same time. Decisions are hidden until both are locked in.
Resolution
If total demand exceeds supply for any resource, the round is overdrawn — both agents score zero. Otherwise, project rewards are tallied.

Compatibility Ratio (M/C)

A single parameter controls the degree of goal conflict. The ratio compares the best joint outcome (M) to the sum of individual optima (C) — determining whether agents must compete, negotiate, or simply coordinate.

Experimental conditions & controls
  • Compatibility ratio (M/C) — Controls goal conflict. M/C = 1.0 means fully compatible projects; M/C = 0.5 means heavily overlapping resource needs. Agents start with uncertainty and must use negotiation to discover alignment.
  • Partner stability — Stable: same partner across rounds, enabling shared history and convention formation. Shifting: one agent's context resets each round, testing whether grounding persists without shared memory.
  • Project rotation — Fixed: same scenario every round. Rotating: new projects each round at the same M/C ratio, testing transferable coordination strategies vs. memorized allocations.
  • Cheap talk toggle — Disable communication entirely as a no-talk baseline to measure the value of language in coordination.
  • Share projects — Instruct agents to reveal project details at the start of each round, an information-sharing intervention that tests whether transparency improves grounding.
  • Theory of mind — Prompt agents to reason about the opponent's goals and likely projects before deciding, a theory-of-mind elicitation intervention.
  • Cross-play — Pair different LLM models (e.g. Claude Sonnet × GPT-5 Mini) to study whether heterogeneous dyads outperform self-play through complementary negotiation styles.
  • Role swap — Each configuration is played twice with first-speaker roles swapped to control for order effects.
