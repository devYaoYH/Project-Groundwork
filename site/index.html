a2a-comm

Benchmarks for agent-to-agent coordination: a shared engine, a shared experiment runner, and a shared judge — one game per environment.

Environments

Run an experiment

uv pip install -e a2a-engine -e expt-runner -e games/negotiation
cd games/negotiation
uv run python run.py experiments/smoke_local.yaml --results-dir ./results

Every run writes a trace plus a RunManifest pinning the code, config hash, dataset hash, and models — so a result can be traced back to the exact conditions that produced it. See docs/CONTRACTS.md.

Static page — deploys to GitHub Pages with no build step. Game viewers and leaderboards are deployed separately by each game and linked above.
